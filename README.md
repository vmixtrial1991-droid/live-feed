# Живая лента 4.0

Веб-приложение для мероприятий: гости по QR-коду вводят имя и отправляют текст или фото —
всё сразу появляется на витрине и на полноэкранном показе. Модерации нет: сообщение уходит
в эфир в момент отправки.

Событий на одном сервере может быть сколько угодно. Каждое заводится в админке и получает
свои три ссылки и QR-код: для ведущего (по паролю), для экрана (без пароля) и для гостей
(с кодом приглашения). События изолированы — свои ссылки, своя база, свои фото, — и удаляются
без хвостов: папка `data/events/АДРЕС` целиком.

Стек: Python + FastAPI + SQLite, без Node.

## Что нового в 4.0

- **Вкладка «Слайдшоу»** в кабинете ведущего: галочка у фотографии в ленте переносит её
  в галерею, отдельной кнопкой галерея выходит на экран. У слайдшоу своя пауза,
  она не трогает ленту.
- **Архив фотографий отделён от ленты**: удаление сообщения убирает строку, но не стирает
  файл; галерея живёт своей жизнью.
- **Правка текста** — своё окно со счётчиком символов, правка видна на экране сразу.
- **Код приглашения вводится руками** и без учёта регистра.

## Установка

### Docker (рекомендуется)

```bash
git clone https://github.com/vmixtrial1991-droid/live-feed.git live-feed
cd live-feed
cp .env.example .env    # вписать ADMIN_PASSWORD
docker compose up -d
```

Админка — `/admin`, пароль из `.env`. Сертификат Let's Encrypt выпускается сам,
если в `.env` прописан `DOMAIN`; без него сайт работает по http.

### Ubuntu/Debian без Docker

```bash
sudo bash deploy/remote-ip.sh          # по IP, http
sudo bash deploy/remote.sh домен.ru    # с сертификатом Let's Encrypt
```

Скрипты ставят nginx, окружение и systemd-сервис; пароль печатается в конце
и лежит в `/etc/live-feed.env`. Повторный запуск безопасен.

### Локально

```bash
python -m pip install -r requirements.txt
python run.py
```

Адрес админки и пароль администратора печатаются в консоли при старте.
