# Сторонние компоненты

«Живая лента» использует следующие сторонние библиотеки. Они не входят в
исходный код проекта, а ставятся из PyPI при сборке (см. `requirements.txt`),
и распространяются под своими лицензиями.

| Компонент | Назначение | Лицензия |
|---|---|---|
| [FastAPI](https://pypi.org/project/fastapi/) | веб-фреймворк | MIT |
| [uvicorn](https://pypi.org/project/uvicorn/) | ASGI-сервер | BSD-3-Clause |
| [python-multipart](https://pypi.org/project/python-multipart/) | разбор загрузки файлов | Apache-2.0 |
| [Pillow](https://pypi.org/project/pillow/) | обработка изображений | MIT-CMU |
| [qrcode](https://pypi.org/project/qrcode/) | QR-коды для подключения зала | BSD-3-Clause |

Лицензии указаны по данным PyPI на момент подготовки файла (ноябрь 2026).
Точные тексты — в пакетах и в репозиториях проектов.

## В чём состоит требование атрибуции Apache 2.0

Собственная лицензия проекта — Apache License 2.0 (файл `LICENSE`). Она
разрешает бесплатное использование, копирование, изменение и коммерческое
применение. Обязательное условие — сохранять уведомление об авторстве
(файл `NOTICE`) и прикладывать копию лицензии при распространении.

Это не требование сторонних библиотек: их лицензии действуют отдельно.
